# Salesforce quickstart

- CLI: `sf` (https://developer.salesforce.com/docs/atlas.en-us.sfdx_cli_reference.meta/)
- Auth: `sf org login web --alias myorg`
- Scratch orgs: `sf org create scratch --definition-file config/project-scratch-def.json`
- Deploy: `sf project deploy start`; retrieve: `sf project retrieve start`
- Trailhead: https://trailhead.salesforce.com/ — record each
  module as a teaching doc under docs/trailhead/.
